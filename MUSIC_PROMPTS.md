# Music and sound prompts

The game ships with placeholder music and sound effects generated by `tools/make_audio.py`. To replace any of them, generate a track with an AI music tool (Suno, Udio, Stable Audio…), export it, and save it in `game/audio/` with the **same file name**. OGG is best for the web version; ask for MP3 or WAV and convert it with:

```sh
ffmpeg -i new_track.mp3 -c:a libvorbis -q:a 4 game/audio/day.ogg
```

Tips:
- **Instrumental only.** Lyrics fight with the dialogue. In Suno, turn on *Instrumental*; elsewhere add "no vocals".
- **Loops:** every track repeats while you're in a scene, so ask for "seamless loop, no intro, no fade out", and trim any intro or ending before saving. 1–3 minutes is plenty.
- **Keep it quiet:** the music sits under the text. Ask for "background music, gentle, not busy".
- **No real artists:** describe the sound instead of naming a band.

## Where each track plays

| File | Plays during |
|---|---|
| `theme.ogg` | Main menu |
| `day.ogg` | Arrival, the lobby, the pool every afternoon, mornings, Monday goodbyes |
| `night.ogg` | The hallways and every art room at night |
| `party.ogg` | The ballroom, the ark at 11:11 |
| `tender.ogg` | The roof, sunrise, Zyx's ship, every romance and every ending card |

Which track plays where is set in `game/audio.rpy` (`BG_MUSIC`).

## Sound effects

Any sound-effect generator works (ElevenLabs Sound Effects, Stable Audio). Save them in `game/audio/sfx/`.

| File | Plays when | Prompt |
|---|---|---|
| `click.ogg` | You pick a choice | `soft short UI click, a muted wooden tap, very short` |
| `rapport_up.ogg` | A guest really likes your answer (+2) | `short sparkly three-note chime going up, magical and warm, cute game UI` |
| `rapport_down.ogg` | A guest is put off (−1) | `short soft two-note chime going down, gentle disappointed game UI sound, not harsh` |
| `whoosh.ogg` | Night falls | `soft airy whoosh with a faint shimmer, like a door to a party swinging open, 1.5 seconds` |
| `ark.ogg` | The ark arrives at 11:11 | `rising shimmering synth swell building to a bright magical chord, cosmic and celebratory, 5 seconds` |
